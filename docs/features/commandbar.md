# Feature: Command bar

Status: **K1–K11, K13–K15 and K17–K37 built.** **K12 partial**: a click on the address row's URL text does not open the bar (BACKLOG S-127). **K16 partial**: Turn Bookmarks into Pinned Tabs stays listed when nothing is left to convert (BACKLOG S-158).
Owner docs: `docs/PRODUCT.md` ("Command bar"). Patches: `0005`, `0022`, and later rows in the series.

⌘T opens a bar over the page. It lists open tabs from every Space, at most four, then archived tabs, at most three, then the omnibox's suggestions, at most six. Typing a URL opens it; anything else is a search (the default engine's, or the engine a keyword names, K18). Commands are a second mode (K8): ⌘T alone lists no command. Chords below are the defaults; the user can change them (shortcuts Z5).

An archived row is one of the archive page's rows (archive A10). A tab of a window the next launch opened again is open, and has no "Archived" row beside its own (archive A13, `ArchiveReopenTest.AWindowOpenedAgainIsNotArchived`). An archived row whose restore brings the tab back to a Space with an Independent session wears that session's cookie mark (sessions S32).

On Windows every chord below is the Mac's with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt (Alt+1–9 for the Spaces themselves). The full map is `docs/features/windows.md` N7.
