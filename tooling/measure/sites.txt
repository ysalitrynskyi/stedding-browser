# The fixed ten-site list used by every memory and warm-startup measurement.
#
# Chosen to be varied in weight (text, media, script-heavy app, docs), popular enough
# to stay online, and stable enough that a number taken today is comparable to one
# taken next year. Changing this list invalidates every baseline measured with the
# old one, so it changes only alongside a re-measurement of the baselines.
#
# Measurements over real sites carry real network and server variance. That is
# tolerable because the gate in docs/QUALITY.md is overhead *relative to vanilla
# Chromium measured the same way on the same machine*, where the variance largely
# cancels. Absolute numbers from this list are not promises.
