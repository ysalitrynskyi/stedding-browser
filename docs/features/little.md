# Feature: Little window

Status: **E2–E5 and E7–E10 built; E1 and E6 partial.** E1 is not centred when no normal window is open (BACKLOG S-157). E6's administrator policy path has not been run (BACKLOG S-129).
Owner: `docs/PRODUCT.md` §5. Code: `chrome/browser/ui/stedding/little_window.cc`.

A link from another application opens in a small popup: no sidebar, no Spaces, no command bar. Its top is the main window's address row. ⌘O (Ctrl+O on Windows), the row's "Open in Stedding" button and the page menu move the page into the last-active normal window, or into a new one when none is open. On the Mac the File and Window menus do the same. A matching route wins (routing D3). With the setting off, the link opens as an ordinary tab.

## Notes

- "Open in Stedding" is one string, the product name, shared by the button, the page menu and the Mac File menu. ⌘O is Open File's chord, which a little window turns into the move.
- "Last-active window" is the last activated normal window of the profile. With the registry (ADR 0016) every normal window shares the Spaces, so the choice decides where the tab lands.
- The row is a toolbar with named buttons (Back, Forward, Reload, "Open in Stedding"), as the main window's is. It has not been heard with a screen reader.
