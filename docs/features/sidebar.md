# Feature: Sidebar density, text size and the collapsed rail

Status: **Y1–Y14, Y16–Y52 and Y54 built. Y53 planned** (the Mac, BACKLOG S-403). **Y15 partial** (screen reader not yet heard, BACKLOG S-129). Measured row size: `docs/PRODUCT.md#ui-spec`.

Comfortable is 44 DIP rows with an 18 DIP favicon. Two browser-wide settings trade that for more rows, or a larger title: a density preset and one text-size step. Comfortable stays the measured size.

## Notes

Density and text size are local state. The cache is process-wide, filled at startup and on every change by a `SidebarDensity` observer, which invalidates each window’s layout. Closed form, page flush, the side and the library panels are profile preferences.

The sidebar on the right (Y34–Y43) is a flag in the layout. `VerticalTabStripRegionView::IsAtTrailingEdge` says the strip takes the window’s trailing edge. `IsOnRight` is what code uses for the handle, the reveal edge, the drop arrow, the keyboard resize, the hover card’s side and Windows’ caption colours. Reading direction stays with `base::i18n::IsRTL`: the Space switcher’s slide, the swipe between Spaces, the down arrow over a pinned row, and the rows.

Not mirrored: the window ground’s diagonal gradient, the shadow of a rail expanded on hover, and macOS’s glass frame (`features::kGlassFrame`, off by default), which stays on the left.
