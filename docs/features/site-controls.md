# Feature: Site controls

Status: **Si1–Si11 built. Si12** is drawn in page info’s colours; its live check has no recorded run. The blocker’s per-site switch is the address-row shield, not a row here (blocker Bk6).

One panel for the site you are on. It is Chromium’s page info, opened from the site chip (toolbar T5), with Stedding’s controls in it: a strip under the title (Copy link, Copy title, Mute tab, Picture in picture, zoom); Chromium’s security, permissions and cookies rows; Chromium’s Extensions row; and, before Site settings, the session, Clear site data, and the dark-pages switches. The command bar’s View Site Information opens the same panel (commandbar K33), including from inside the page while the address row is hidden (toolbar T40). There is no second panel, no new button, no setting and no new chord. Each control runs the window’s own command.

On Windows every chord below is the Mac’s with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt (`docs/features/windows.md` N7).

## Privacy

Nothing here is fetched. Copy writes to this computer’s clipboard. Zoom changes the page. Clear site data deletes data in one jar. The rows read the profile’s settings. Copy title and Clear site data add toast ids to Chromium’s toast list. Page info’s own metrics are unchanged. With metrics reporting off, the default (`docs/PRIVACY.md`), none of it leaves the computer.

## Where the code is

Rules: `chrome/browser/ui/stedding/site_controls.{h,cc}`.

Views: `chrome/browser/ui/views/page_info/stedding_site_controls_view.{h,cc}`, added to `PageInfoMainView` when `PageInfoBubbleSpecification::Builder::ShowSteddingSiteControls` is set (the site chip, `LocationBarView::ShowPageInfoDialog`; View Site Information, `ShowPageInfoDialogImpl`).

Clear site data: `ClearSiteDataAndReload` in `chrome/browser/ui/stedding/site_cookies.cc`. Copy title: `CopyTitle` in `copy_link.cc`. The extensions menu: `ShowExtensionsMenu` in `chrome/browser/ui/views/commandbar/address_row_controls.cc`.

## Running the tests

```bash
tooling/dev test site-controls
tooling/dev test browser 'SiteControlsTest.*:SpaceJarTest.ClearingASitesDataStaysInThatJar:IsolationMarkTest.TheSiteControlsNameTheJar:HiddenRowControlsTest.TheSiteControlsExtensionsRowOpensInsideThePage'
```

`tooling/dev test site-controls` runs the unit filter only (`SiteControlsRulesTest`, `SiteControlsViewTest`, `SiteCookiesTest`, `CopyLinkTest.CopyTitleWritesThePagesTitle`). `SiteControlsTest.*` and `HiddenRowControlsTest.*` run in the browser leg’s serial part.
