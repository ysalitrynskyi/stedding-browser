# Feature: History and Downloads in the sidebar

Status: **Pn1–Pn16 built**, on by default. The live checks `sp_*` in `acceptance.md` have no recorded run.

History and Downloads open in the sidebar’s column, in place of the essentials and the tab list, between the top row and the foot. The foot stays (sidebar Y44): the archive line, the update pill, and the bottom row. ⌘Y (Ctrl+H) opens History; ⇧⌘J or ⌥⌘L (Ctrl+J) opens Downloads; the same key again closes the panel. The other key switches panels.

Each panel is `chrome://stedding-library/history` or `/downloads`. Data comes from Chromium’s `BrowsingHistoryHandler` and `DownloadsDOMHandler`. Verbs they lack go through `stedding::LibraryHandler` (open in the window, Copy File, Move to Trash, close, Open as Page). Which panel is open is the window’s `stedding::SidebarPanels`, so the keys, the menus and the command bar’s Show History and Show Downloads rows work without the views. `stedding::SidebarPanelView` is created when a panel opens and dropped, after the close has returned, when it closes.

Chromium’s side panel is not used. At this pin its History entry is behind a flag that is off, it has no Downloads entry, and it is a column on the window’s right.

## While a panel is open

The tab list stays under the panel. A Space switch, ⌘T, a new tab or a tab closed by key still changes it, and it shows again when the panel closes. Rows cannot be dragged while it is hidden.

The panel keeps its search and its scroll only while it is open. A switch or a close drops them. No panel is open after a restart.

Keys and menus that are not History’s or Downloads’ still work, whether or not the focus is in the panel (Pn1).

## What still opens the pages

The panels replace the keys, the menus and the command bar rows, which run the window’s History and Downloads commands. These still open the pages: the History page’s own links, the downloads bubble’s “See all downloads”, a click on the downloads button when the bubble is not available, the toolbar’s pinned History button, and Open as Page.

## Privacy

Nothing is fetched (Pn8). The History panel uses Chromium’s history handler, which can read web history only for a profile signed in to Google with history sync on. Stedding offers no sign-in (`docs/PRIVACY.md`, “Sync”), so the panel reads local history. Copy File writes a path only when the user chooses it (Pn10).
