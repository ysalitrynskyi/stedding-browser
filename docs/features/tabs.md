# Feature: Tab rows

Status: **R1–R8, R10–R18, R20, R21 and R23–R64 built, except R19, R22 and R60. R19 partial** (each pane of a split takes its own number; BACKLOG S-102). **R22 partial** (the command bar's Move Tab row acts on the active tab only; S-127). **R60 planned** (S-92).

Owner docs: `docs/PRODUCT.md#ui-spec`. Patches: `0017`, `0019`, `0060`, `0070`, `0075`, `0077`, `0080`, `0110`.

The close control is laid out only while the pointer is on the row or the control has keyboard focus. The title does not re-elide when it appears. An essentials card that plays audio keeps its favicon. On a Space pin the control is a minus or an x (pins H29).

On Windows every chord below is the Mac's with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt (Alt+1–9 for the Spaces). The map is `docs/features/windows.md` N7.
