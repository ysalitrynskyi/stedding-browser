# Feature: Windows, and the Space registry

Status: **G0, G1 and G3–G10 built. G2 not built (S-94). N1–N7 and N10–N14 built. N8 and N9 partial (S-129). N15 on by default; the live checks in S-234 are open.** Windows ships. Still open on that port: signing and SmartScreen, CI (S-56, S-49), and the finger-following Space swipe (WIN-12).

Owner docs: `docs/decisions/0016-space-registry.md`, `docs/PRODUCT.md` §10.

A second window of the same profile shares the Space list: order, names, icons and colours. Pinned tabs and essentials stay tabs of one window. A ghost pin, the same pin shown in every window, is G2 and is not built.
