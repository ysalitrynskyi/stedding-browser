# Stedding 0.5.1

A fix for a crash on the Mac, an address row that kept a colour the page never showed, and two
things people coming from Arc asked for: Shift-click to peek at any link, and a menu on the
download toast.

## Fixed

- **Mac: a right-click no longer closes Stedding.** In 0.5.0, a right-click on a link or a tab
  closed the browser whenever a Space had a session of its own. The coloured dot beside a
  Space's name in Open Link in Space, Move to Space and Always Open is drawn in a way the Mac's
  own menus take. Windows was not affected.
- **The address row keeps to colours the page shows.** A page whose top is a photograph and that
  declares a colour it never shows, as start.me's start page does with a bright blue, left the
  address row in that colour. The row now takes a page's declared colour only where the top of
  the page shows it, and otherwise keeps the window's own.

## New

- **Shift-click opens any link in a peek (GitHub discussion 115).** From any tab, pinned or not,
  to any site, Shift-click opens the link in a peek over the page, as Arc's Shift-click did.
  Open as Tab and Open in Split View keep it. Settings → Stedding → Peek and little windows →
  **Shift-click a link to peek at it**, on by default; off, Shift-click opens a new window as
  before.
- **A menu on the download toast (GitHub discussion 116).** Right-click a finished download in the
  toast a new download shows: **Move to Trash** (Move to Recycle Bin on Windows), from where it
  can be put back, and **Remove from List**, as in the Downloads panel.

## Chromium

- Built on Chromium 157.0.8103.79, M157's newest release at full rollout, as 0.5.0 was.

## Install

- **macOS** (Apple silicon, macOS 13 or later): `Stedding-0.5.1-arm64.dmg`, signed and
  notarized. Open it and drag Stedding to Applications.
- **Windows** (10 and 11, x64): `Stedding-0.5.1-win-x64.exe`, installs for you alone. It is not
  signed yet: in SmartScreen click **More info**, then **Run anyway**, once.

Installed copies update themselves (Mac from 0.2.0 beta 16, Windows from 0.2.0 beta 19).

## Known limits

- The Windows installer is unsigned (`S-56`).
- Netflix, Disney+, Prime Video and Spotify's web player do not play yet (`S-270`).
- Spaces that share a session share their essentials; a Space's own essentials with shared
  sign-ins are not offered (GitHub issue 87, `S-445`).
- Pinned tabs and essentials are per window; a new window does not show them yet (GitHub issue
  111, `S-94`).
- Finished downloads missing from the Downloads list (GitHub issue 90) are not understood yet; the
  steps that lead there would help.
