# Stedding 0.4.0 beta 19

Password managers now work in a peek, and Stedding moves to Chromium 157.0.8103.79, a security
update.

## Fixed

- **Password managers in a peek (GitHub issue 102).** While a peek over a pinned tab is open,
  its page is the window's active tab to extensions. A password manager that fills the active
  tab, as Bitwarden's popup and keyboard shortcut do, now fills the login in the peek instead of
  the pinned page under it, and keeps filling it after **Open as Tab** with no reload.
- **Reload in a peek (GitHub issue 102).** F5, ⌘R (Ctrl+R on Windows), the address row's reload
  button and the page's own menu reload the peek's page, not the pinned page under it. The
  menu's Reload was greyed out there.
- **Copy Link on a page with no address to share.** On a split's "Choose a tab" pane, the new
  tab page and a Space's own page, ⇧⌘C (Ctrl+Shift+C) copied an internal address and said "Link
  copied". It now leaves the clipboard as it was.
- **Windows: a crash while quitting.** Quitting soon after Settings had asked Windows whether
  it holds passkeys could crash the browser on its way out. The fault is in Chromium's own code,
  and Stedding fixes it.

## Security

- Chromium 157.0.8103.79, M157's newest stable release, with Chromium's security fixes since
  157.0.8103.51.

## Install

- **macOS** (Apple silicon, macOS 13 or later): `Stedding-0.4.0-beta.19-arm64.dmg`, signed and
  notarized. Open it and drag Stedding to Applications.
- **Windows** (10 and 11, x64): `Stedding-0.4.0-beta.19-win-x64.exe`, installs for you alone.
  It is not signed yet: in SmartScreen click **More info**, then **Run anyway**, once.

Installed copies update themselves (Mac from 0.2.0 beta 16, Windows from 0.2.0 beta 19).

## Known limits

- The Windows installer is unsigned (`S-56`).
- Netflix, Disney+, Prime Video and Spotify's web player do not play yet (`S-270`).
- Spaces that share a session share their essentials; a Space's own essentials with shared
  sign-ins are not offered (GitHub issue 87, `S-445`).
- In a peek, an extension's toolbar button without a popup, and a keyboard shortcut that names
  its tab, still act on the pinned tab under it (`S-473`).
- On Windows, ending a tab's rename with Enter or Escape now and then leaves the keys on a
  sidebar row instead of the page; a click on the page gives them back (`S-474`).
- Finished downloads missing from the Downloads list (GitHub issue 90) are not understood yet; the
  steps that lead there would help.
