# Stedding 0.4.0 beta 9

An empty Space shows its own page, folders that collapse when they are pinned, a link opened in
another Space from its menu, pinned extensions back in the sidebar's address field, and no
Install chip in the address bar. On Chromium 157.0.8103.31.

## New

- **Open Link in Space.** Right-click a link: **Open Link in Space** lists the window's other
  Spaces. The link opens in a new tab of the Space you pick, with that Space's own sign-ins
  when it has an independent session, and the window goes there (GitHub issue 75).

## Changed

- **An empty Space shows its own page.** Switching to a Space with no tabs, closing a Space's
  last tab, or a Clear that leaves nothing now shows the Space's quiet page from beta 8, with
  no row in the sidebar, rather than opening a New Tab.
- **No tab group chips on the New Tab page.** The sidebar lists tab groups in their Space.
  Chromium's chip for every saved tab group, one an extension makes around a tab it drives
  included, no longer appears on the New Tab page's bookmarks bar, in every Space. The
  bookmarks bar's own menu can still turn "Show tab groups" on.
- **Install as an app is in the site panel only.** The address bar no longer shows Chromium's
  Install chip; the site panel's row installs the page.
- **The peek settings say what they are for.** Settings › Stedding › Peek and little windows
  says that a link from another app opens in a window of its own whatever the peek settings
  say, and that "Show a peek" is for a link from a pinned tab (GitHub issue 74).

## Fixed

- **A pinned folder collapses.** Collapsing a folder hides its pinned tabs that are awake, all
  but the one on screen. A pinned tab you leave while its folder is collapsed still stays in
  view while it is awake (GitHub issue 76).
- **Pinned extensions show in the sidebar's address field** when there is room for them, and
  come back when the sidebar is widened again (GitHub issue 45).

## Install

- **macOS** (Apple silicon, macOS 13 or later): `Stedding-0.4.0-beta.9-arm64.dmg`, signed and
  notarized. Open it and drag Stedding to Applications.
- **Windows** (10 and 11, x64): `Stedding-0.4.0-beta.9-win-x64.exe`, installs for you alone.
  It is not signed yet: in SmartScreen click **More info**, then **Run anyway**, once.

Installed copies update themselves (Mac from 0.2.0 beta 16, Windows from 0.2.0 beta 19).

## Known limits

- The Windows installer is unsigned (`S-56`).
- Netflix, Disney+, Prime Video and Spotify's web player do not play yet (`S-270`).
- A peek over the page shows no permission prompt of its own; Open as Tab and allow it there.
- Opera is not offered on the import step.
- This build is on Chromium 157.0.8103.31; Chromium's newer 157 point release comes in beta 10.
- Chromium's built-in list of sites that must load over HTTPS lapses for this build on
  13 December 2026; a release on a newer base comes before then.
