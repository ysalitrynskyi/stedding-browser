# Feature: Splits

Status: **J1, J4 and J6–J16 built. J2 partial** (⌃⇥ counts a split once; ⌘1–9 gives each pane a number; BACKLOG S-102). **J3 and J5 planned** (S-102).

Owner docs: `docs/PRODUCT.md` §4. The rows land with the patches that implement them (`0075` for J10–J15, `0076` for J16).

A split is one row and one unit for every sidebar verb. The model is Chromium's split view.

## Running the tests

```bash
tooling/dev test splits
```

`tooling/dev test browser` runs the browser tests the rows cite.
