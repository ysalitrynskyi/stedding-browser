# Feature: Peek

Status: **P1–P19 built.** On by default (`PLAN.md` decision 2). Settings › Stedding › Peek and little windows, "Open links from pinned tabs in a peek", turns it off.

A link from a pinned tab that would leave the pinned site opens in a peek: a little window (`little.md`) over the window, nearly its size, while the pinned tab stays. "Pinned" is either tier, an essential or a pin of a Space. The peek is a whole tab in a window of its own, so dialogs, file choosers, permissions, the popup blocker and the address row work as in any tab. Its row has "Open as Tab" (⌘O) and "Open in Split View" (⇧⌘O); either moves that page into the window without loading it again. Escape, ⌘W or a click on the window it came from closes it. A peek is never saved with the session.

Links that navigate the tab are `PeekNavigationThrottle`, registered for renderer-initiated main-frame navigations in a pinned tab of a normal window. Links that ask for a new tab are checked at the top of `chrome::Navigate()`. The window is `stedding::OpenPeek` (`chrome/browser/ui/stedding/peek.h`). The moves into the window are the little window's (`PromoteLittleWindow`).

## Not in this cut

- A link from a pinned tab that the server redirects to another site stays in the pin (`docs/history/plan-2026-09-26.md` CMD-29). The throttle judges the link, not where the server sends it.
- Option-click (Alt-click) is Chromium's download. It does not peek.
