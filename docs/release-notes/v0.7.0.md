# Stedding 0.7.0

Stedding moves to Chromium 158. ⌃⇥ now changes the tab only when you let go of ⌃, only the
Space you are in shows its icon in colour, and the Mac's updater is Sparkle 2.10.1.

## Changed

- **⌃⇥ changes the tab when you let go of ⌃.** Stepping through your recent tabs with ⌃⇥
  used to show each page as you passed it, so the pages you stepped past flashed by. The page on
  screen now stays put while you step: the strip of recent tabs moves its highlight, and letting
  go of ⌃ shows the tab it is on. Escape keeps the tab you started on. A quick tap still goes
  straight back to the tab you were on before. (GitHub issue 123)
- **Only the Space you are in is in colour.** The other Spaces' icons in the switcher are grey
  and fainter, in the open sidebar and in the rail, so the Space on screen stands out at a
  glance. A Space's session badge keeps its colour, and a Space you drag a tab onto lights up
  in colour as before. (GitHub issue 122)

## Chromium

- Built on Chromium 158.0.8127.37, with the security fixes Chromium made in M158.
- As in Chrome 158, XSLT is off: an XML page that asks for an XSLT stylesheet shows its XML
  and a note that the browser does not support XSLT.

## Updates

- The Mac's updater is Sparkle 2.10.1. It fixes release-notes links that contain spaces, an
  update installed early when the app's path is stored in a different Unicode form, and some
  translations of "Install on Quit".

## Install

- **macOS** (Apple silicon, macOS 13 or later): `Stedding-0.7.0-arm64.dmg`, signed and
  notarized. Open it and drag Stedding to Applications.
- **Windows** (10 and 11, x64): `Stedding-0.7.0-win-x64.exe`, installs for you alone. It is not
  signed yet: in SmartScreen click **More info**, then **Run anyway**, once.

Installed copies update themselves (Mac from 0.2.0 beta 16, Windows from 0.2.0 beta 19).

## Known limits

- The Windows installer is unsigned (`S-56`).
- Netflix, Disney+, Prime Video and Spotify's web player do not play yet (`S-270`).
- Spaces that share a session share their essentials; a Space's own essentials with shared
  sign-ins are not offered (GitHub issue 87, `S-445`).
- In a window whose pinned run holds a split, that run keeps its order when another window
  reorders it (`S-94`).
- An exported sidebar file, and the sidebar's backups, hold a live folder's rows as ordinary pins
  (`S-478`).
- A second Space made by sync before 0.6.0 stays until you delete it (`S-494`).
- A peek closed from outside, by its pinned tab closing, the pinned page going to another site,
  the window closing or the browser quitting, does not ask "Leave site?", and what was typed in
  it is lost.
- A pin whose page and site were never opened in Stedding shows the generic globe until chosen;
  the join sheet counts "1 folders" (`S-497`).
- Finished downloads missing from the Downloads list (GitHub issue 90) are not understood yet; the
  steps that lead there would help.
