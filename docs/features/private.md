# Feature: Private windows wear a different coat

Status: **V1–V3 and V6–V9 built. V4 and V5 withdrawn.**
Owner docs: `docs/PRIVACY.md`, `docs/PRODUCT.md` §5. Patch: 0034.

A private window (⇧⌘N, Ctrl+Shift+N) is an incognito profile (`stedding::IsPrivateWindow`). It is told apart at a glance and leaves nothing in the sidebar's model, the session or the archive. It paints a flat graphite ground with no Space tint, its title row reads "Private", it has no Space switcher, and the address row keeps Chromium's avatar button hidden (V4 withdrawn).

## Notes

- Chromium forces a dark, grayscale colour key for incognito, and a normal window with Chrome's Grey colour in dark mode gets the same key, so the key's colour fields cannot say "private". The window says it with the mark in the app-controller slot (V1, V9).
- The Space chords (⌃1–9, ⌥⌘←/→, and the Windows equivalents) do nothing in a private window: there is no model to act on (spaces B29). Clear and the folders chord stay enabled (V8, folders F30).
- "Private" is the title row's accessible name.
