# Feature: Copy link

Status: **L1–L7 built** (L7 in patch 0083, the little window's button and toast released in 0.3.0 beta 22, S-325). **L7's check mark** leaves in about a tenth of a second, not the 1.5 seconds the timer asks for (BACKLOG S-327).
Owner docs: `docs/PRIVACY.md` (the tracking strip), `docs/PRODUCT.md`. Patches: `0016`; L7 in `0083`.

⇧⌘C copies the page's URL. ⌥⇧⌘C copies a Markdown link with a rich-text twin. Both drop tracking parameters when the setting is on. The Markdown title is the page title, or the host when the title is empty. With rows selected, both copy every selected page (tabs R21). A split is one row, so on a split alone they copy the page in focus. A button at the address field's right end does the same with a click, and an Option-click copies the Markdown link (L7).

Chords below are the defaults; the user can change them (shortcuts Z5). On Windows every chord is the Mac's with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt. The full map is `docs/features/windows.md` N7.
