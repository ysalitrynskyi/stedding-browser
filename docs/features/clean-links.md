# Feature: Clean links

Status: **Cl1–Cl14 built.** Patch `0089`.

A page the user opens loads without the tracking parameters a copied link already loses (copy-link L2), so the site's server never receives them. The address field, the page's `location`, history and a later copy show the clean address. A link through a known redirect page that carries its target in its own address goes straight to the target. The redirect page is never asked for. Both tables are compiled in. Nothing is fetched.

`stedding::CleanLinksThrottle` (`chrome/browser/ui/stedding/clean_links_throttle.cc`) is a URL loader throttle for a navigation's own loader, made while `kArcStyleWindow` is on. It rewrites the request in `WillStartRequest`. The loader turns that into an internal 307 before anything reaches the network. The address rules are in `clean_link.cc`, shared with copy-link.

## Limits

- The tab's navigation entry keeps the address the navigation started with as its original request address. Session restore and tab restore write that to disk with the entry. History (Cl6) does not hold it.
- `IsCleanLinkHop` cannot tell Stedding's hop from a server redirect of the same shape, so history leaves those out too, whether or not the setting is on. Nothing else in the chain is dropped.
- The referrer on a skipped redirect follows the linking page's referrer policy. Under the default `strict-origin-when-cross-origin` the target sees the linking page's origin.
- A browser-side prefetch carries no navigation and is not cleaned, so a prefetched tracked address can reach its server before a click. A prerender of a redirect page is cancelled by its cross-site internal redirect.
- Space routing, little windows and Peek's new-tab path see the address before the throttle runs. Peek already judges a redirect link by its target (`PeekTargetOf`, peek P15), with a wider rule than Cl3, and that rule is unchanged.
- A page that sends itself, with no click, to a different path with a tracking parameter, and is sent back again, is not caught by Cl13. It keeps loading until its site is a kept site (Cl8).
- There is no per-site command-bar row that reloads the page as it was opened. Kept sites are added in Settings. Private windows list no preference rows (commandbar K15).
- `gbraid`, `wbraid`, `ttclid` and `li_fat_id` are not in the table. Adding them would change copying too (copy-link L2).
