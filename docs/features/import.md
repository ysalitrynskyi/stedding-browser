# Feature: Import

Status: **I1–I4, I6, I8–I16, I18, I20–I23 and I26–I27 built. I28–I32 and I34–I42 built** on welcome step 2. **I24 partial** (BACKLOG S-129). **I25 partial** (BACKLOG S-51). **I5 and I7 planned** (BACKLOG S-103). **I17 and I19 withdrawn. I33 a gap.** Settings and command bar rows for Dia and for Safari’s export are not built (BACKLOG S-101).

An Arc user gets their sidebar back: Spaces with icon and colour, essentials, pinned tabs, folders with nesting, and the other tabs, read from Arc’s `StorableSidebar.json`, summarised before anything is applied, and inserted unloaded.

A Dia user, and anyone with the file Safari exports, gets bookmarks, history and saved passwords the same way: summed up first, brought in by one button, counted in one result line, and never twice (I28–I42).

Owner docs: `docs/PRODUCT.md` §1. Patches: 0026 (I1–I4, I8–I12), 0032 (I13–I16), 0038 (I6, I21–I23), 0097 (I28–I32, I34–I42).

## How it runs

History and passwords (I22, I23, I30, I31) are read from copies in a temporary directory, on the thread pool, and written on the UI thread. Arc’s copies are deleted when the read ends. The Mac keychain password is asked for on that pool thread. Safari’s file is read where the user chose it. Nothing an import reads leaves the machine (`docs/PRIVACY.md`).
