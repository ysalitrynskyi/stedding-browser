Owner docs: `docs/decisions/0015-spaces-filter-one-tab-strip.md`, `docs/PRODUCT.md#ui-spec`. Patches: `0004`, `0021`, `0025`, `0052`, and later patches in `patches/README.md`.

## What a Space is

A Space is a named, coloured set of tabs inside one window. Every tab belongs to exactly one Space, except Chromium-pinned tabs (the essentials row), which are in every Space. Only the active Space's tabs are visible; the rest stay in the one tab strip, hidden (ADR 0015). The content pane shows a tab the sidebar shows.

On Windows every chord below is the Mac's with ⌘ read as Ctrl and ⌥⌘ as Ctrl+Alt (Alt+1–9 for the Spaces). The map is `docs/features/windows.md` N7.

tooling/dev test spaces
