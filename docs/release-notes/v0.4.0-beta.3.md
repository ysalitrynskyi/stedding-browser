# Stedding 0.4.0 beta 3

Duplicate in the short tab menu, and the address field in a split. On Chromium 157.0.8103.31.

## New

- **Duplicate** is back in the short tab menu, above *Copy Link* (GitHub issue 63). The copy of
  an essential or a pinned tab is a plain tab, placed where a new tab opens; the essential or
  the pin stays the only one.

## Fixed

- **The buttons at the end of a centred address field** (*Install*, *Copy Link*) answer a click
  on Windows (GitHub issue 14).
- **In a split, the address field belongs to the pane you are in** (GitHub issue 14). It sits
  over that pane alone at every field width, and moves with the focus, instead of running across
  both panes.
- **A pinned tab in a collapsed folder** folds away again when it is put to sleep (GitHub
  issue 35).

## Install

- **macOS** (Apple silicon, macOS 13 or later): `Stedding-0.4.0-beta.3-arm64.dmg`, signed and
  notarized. Open it and drag Stedding to Applications.
- **Windows** (10 and 11, x64): `Stedding-0.4.0-beta.3-win-x64.exe`, installs for you alone.
  It is not signed yet: in SmartScreen click **More info**, then **Run anyway**, once.

Installed copies update themselves (Mac from 0.2.0 beta 16, Windows from 0.2.0 beta 19).

## Known limits

- The Windows installer is unsigned (`S-56`).
- Netflix, Disney+, Prime Video and Spotify's web player do not play yet (`S-270`).
- On Windows, in a split in a narrow window (about 1040 pixels wide with the sidebar open),
  the address field still runs across both panes when the right pane is the active one: the
  window's own buttons leave it no room over that pane (`S-370`). At 1300 pixels and wider it
  sits over the pane you are in.
- Chromium's built-in list of sites that must load over HTTPS lapses for this build on
  13 December 2026; a release on a newer base comes before then.

## How it was checked

Each fix has a test that failed before it. On the final build every unit and browser test
passed on both platforms: on the Mac 1348 unit tests and 681 browser tests (162 of them one at a
time), on Windows 1339 unit tests and 639 browser tests (178 one at a time). The fixes' tests
passed again with the extra checks for dangling pointers and broken assumptions on both. With the
real pointer and keyboard, on the Mac's signed build and on Windows' installed copy, the
acceptance scripts passed (the core loop, a relaunch, drags, keys); at the Compact field width a
click on Copy Link copied the address and a click on Install opened its dialog; and in a split
the address field moved to the pane clicked, on Windows at 1300 pixels wide and wider. Apple's
distribution check passed. On Windows an installed 0.4.0 beta 2 updated itself to this release
through a copy of the update feed and came back with its tabs, and the installer repaired,
uninstalled keeping the profile, and installed again.
