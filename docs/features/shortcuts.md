# Feature: Shortcuts

Status: **Z1–Z23 built.** Z5 and Z10–Z22 are S-91 (patch 0100), released in 0.3.0 beta 16. Z23 is S-321, released in 0.3.0 beta 22. No ADR yet for storing the chords in local state; Decisions is the record.
Owner docs: `docs/ROADMAP.md` (the quality bar), `docs/PRODUCT.md` (shortcuts).

chrome://settings/stedding has a Shortcuts block. Every command a chord of the shipped tables reaches has a row, and the user can change its chords: add one, take one off, turn the command's keys off, or put its defaults back. Below the rows, the block keeps a reference of the shipped binary: every Chromium chord Stedding rebinds (Z2) and the platform's notes (Z3), read from the accelerator tables at startup. A change that remaps a chord adds its divergence here. Nothing is hand-typed.

The user's chords are one overlay on the shipped tables, applied where the tables are read: the views accelerator table on Windows and Linux, and on the Mac the menu's key equivalents and the table of chords coded by key. Menus, the command bar and the toolbar's tooltips read through the same lookups, so they name the user's chord.

## Running the tests

```bash
tooling/dev test shortcuts
```

The browser tests are `ShortcutRebindTest.*`, `ShortcutRecordTest.*` and `ShortcutSettingsTest.*`. They press keys into a window, so they run one at a time. GitHub CI does not run them (S-49).

## Notes

- ⇧⌘D shows or hides the address row on its own (toolbar T10). Bookmark All Tabs keeps its menu item.
- Inside a little window (little E2, E7), ⌘O sends the page into a tab (the File menu's row reads "Open in Stedding" there), ⇧⌘O into a split, and Escape closes the window. ⌃⌘N is the split (Z3). No chord opens a little window (little E5).
- The sideways wheel that steps through the Spaces (spaces B39) is not a key, so this block does not list it. `docs/SHORTCUTS.md` does.
- The welcome flow and a few Settings lines still name the shipped chords (welcome W6, settings T13). Chromium windows that print a chord once when they open show the chord they read then.

## Decisions

- The chords live in local state, so they are the machine's. The Mac's menu bar and the accelerator tables are one per app. A profile used by two people shares one set of shortcuts.
- Rows are keyed by stable names in the catalog. A name, once shipped, stays: add rows, never rename one (`ShortcutCatalogTest.NamesAreStable`).
- A user chord beats a default, including a default a later release adds (Z20).
