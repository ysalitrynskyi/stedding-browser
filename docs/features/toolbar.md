# Feature: Toolbar and page bar

Status: **T1–T8 and T10–T49 built. T9 withdrawn.**

The address row is the top of the page card. The same gutter as the card, 6 DIP (`card_gutter`), on the three free sides, and the page's own colour when the page has one (T3, T15). One hairline, a tenth of the contrast colour, marks where the row meets the page (T15).

On Windows, ⌘ in a chord below is Ctrl and ⌥⌘ is Ctrl+Alt, except where the row names the Windows chord. ⌘E is Ctrl+Alt+E (T39). Full screen is F11 (T45). Alt+1–9 switch Spaces. The full map is `docs/features/windows.md` N7.

Owner docs: `docs/PRODUCT.md#ui-spec`.
