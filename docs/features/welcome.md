# Feature: Welcome flow

Status: **W1–W19 built.** Step 2 offers Chrome, Edge, Brave, Vivaldi and Dia when they are found (import I43, I32), a Safari export file (I41), Chromium's own importers -- Safari and Firefox on macOS, the old Edge, Internet Explorer and Firefox on Windows -- each with only the boxes it can fill (I44), and a bookmarks HTML file. Opera is not offered.

Owner docs: `docs/PRODUCT.md` (first run, import), `docs/PRIVACY.md` (the chooser).

`chrome://stedding-welcome` is a child dialog of the browser window, a `views::DialogDelegate` around a WebView, 960 by 640. It opens one loop turn after `BrowserView::Show`. It is not window-modal, so quitting and closing the window still work, and it is not a `WebDialogView`, so the first close dismisses it. It returns on the next window until the profile finishes or skips it. `--no-first-run` suppresses it; `--stedding-welcome` forces it; `--stedding-welcome=<step>` opens that step (`search`, `import`, `appearance`, `behaviour`, `default`, `keys`).

Seven steps, plus a welcome screen: search engine, import, appearance, behaviour, privacy, default browser, keys. The accent is deep slate by day and a light slate at night (`docs/VISION.md`, "Brand and voice"). Nothing on the page is fetched.

Chromium's search-engine chooser does not open over the first page while this flow has not been shown. `SearchEngineChoiceTabHelper` opens this dialog instead.
