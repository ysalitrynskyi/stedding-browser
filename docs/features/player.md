# Feature: Mini player

Status: **Mp5 built. Mp2, Mp4 and Mp6 being built** for the next release, with Chromium's own picture-in-picture window (the owner, 2026-11-13: "you can start with window"). **Mp1 and Mp3 planned** (BACKLOG S-95).
Owner docs: `docs/PRODUCT.md` §9. Patch: 0060 (Mp5).

Picture-in-picture is meant to be a child of the page card, not Chromium's always-on-top window. No model. Until Mp1 exists, ⌥⇧⌘P opens Chromium's own window.
