# Feature: Windows, and the Space registry

Status: **G0–G22 built; G2 and G13–G22, pins and essentials in every window (ADR 0035), checked on Windows, the Mac owed (S-94). N1–N7 and N10–N14 built. N8 and N9 partial (S-129). N15 on by default; the live checks in S-234 are open.** Windows ships. Still open on that port: signing and SmartScreen, CI (S-56, S-49), and the finger-following Space swipe (WIN-12).

Owner docs: `docs/decisions/0016-space-registry.md`, `docs/PRODUCT.md` §10.

A second window of the same profile shares the Space list: order, names, icons and colours. Pinned tabs and essentials are the profile's, a tab of each in every window, as Arc has them (G2, G13–G22, ADR 0035).
