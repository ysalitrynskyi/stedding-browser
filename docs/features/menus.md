# Feature: Menus

Status: **M1–M13 built.**
Owner: `docs/PRODUCT.md`, `docs/PRIVACY.md`.

The tab, page and app menus lead with what this browser does, with every chord drawn. "Short context menus" (`stedding.menus.short`, on by default) is that set. Off, Chromium's rows come back.

## Notes

- The page and app menus keep Chromium's builders. Rows are hidden by `IsCommandIdVisible`, from `stedding::menu_rules` and the short-menus setting. The tab menu's kind rows are hidden the same way, from the tab's tier.
- Screenshot and Spaces are submenus whose ids live on `AppMenuModel`, in the `IDC_STEDDING_` range, not in `chrome_command_ids.h` (docs/HANDOFF.md trap 19). The rows are English literals. A container id is not registered with the command updater, so each submenu answers its own enabled state.
- The sidebar's background menu keeps New Tab, Reopen Closed Tab, Name Window, Collapse, the switch to the other strip (M9) and Task Manager. With short menus on, Bookmark All Tabs, Tab Search, the Glic pins and the auto-expanding toggle go. The vertical-tabs feedback row goes either way.
- The folder header's Move Tabs Out dissolves the folder in place, so a nested folder's tabs stay in the folder above it (folders F26). Close Folder's Tabs leaves the folder first when it holds the active tab, then closes its tabs of this Space.
